# Vehicle Rental Management System

A console-based Vehicle Rental Management System developed using Python and SQLite.

## Technologies Used

- Python
- SQLite
- SQL
- Object-Oriented Programming (OOP)

## Features

### Admin

- Add vehicles
- View vehicles
- Update vehicle details
- Delete vehicles
- Manage vehicle availability

### Customer

- Customer registration
- Customer login
- View available vehicles
- Search vehicles
- Sort vehicles by price
- Filter vehicles by type
- Rent vehicles
- Payment processing
- View rental history
- Return vehicles
- Track actual return date
- Detect overdue rentals
- Calculate late fines
- Pay fines

## Database

The application uses SQLite for permanent data storage.

### Tables

- `vehicles` - Stores vehicle information
- `customers` - Stores customer information
- `rentals` - Stores rental, payment, return, and fine information
